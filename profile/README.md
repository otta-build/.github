# Otta

**AI agents that ship production code — and prove it works.**

Otta is a GitHub-native autonomous dev platform. An idea becomes a shipped, cost-accounted change with just two human gates — approve the plan, approve the promote. In between, agents test-drive, visually verify, and gate every change before it merges.
